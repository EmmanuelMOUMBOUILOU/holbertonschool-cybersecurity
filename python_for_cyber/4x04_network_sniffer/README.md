
# Python - Network Sniffer (PySniffer)

## Description

PySniffer is a Python-based network traffic analysis project developed as part of the Holberton School Cybersecurity curriculum.

The project aims to progressively build a lightweight network packet sniffer using Scapy.

## Requirements

- Python 3.8 or higher
- Scapy
- Linux (Ubuntu, Kali Linux, or ParrotOS)

## Installation

Create and activate a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install Scapy:

```bash
python3 -m pip install scapy
```

## Usage

Make the script executable:

```bash
chmod +x sniffer.py
```

Run the program:

```bash
./sniffer.py
```

Expected output:

```text
[INFO] PySniffer initialized.
```

## Project Structure

- `sniffer.py`: Main Python script.
